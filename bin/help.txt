aivp — Awesome AI Video Prompts

90 curated prompts that diff 10 scenes across 9 video models, plus 2509
attributed prompts imported from 10 MIT open-source collections. A structural
translator and a linter are included. Zero dependencies.

USAGE
  aivp <command> [options]

CURATED LAYER
  list [--models]             List scenes (add --models for coverage)
  show <scene> [--model id]   Print a scene, or one model's prompt
  search <query>              Keyword search across curated scenes
  models [--active]           Print the model capability registry

IMPORTED LAYER
  library                     Sources, families, confidence tiers
  find <query>                Search the imported corpus
  get <record-id>             One record with full provenance
  credits [--source <id>]     Attribution lines
  stats                       Structural statistics per model family
  families [--unverified]     Capability registry + verification level per family
  inspect <record-id>         Prompt anatomy: camera, audio, duration

TOOLS
  translate <from> <to> [f]   Convert a prompt between model formats
  validate <model> [file]     Lint one prompt (stdin when file is omitted)
  validate --all              Lint every curated prompt
  export [--format json|md]   Emit the curated dataset
  help                        This text

OPTIONS
  --model <id>       Restrict to one model
  --category <c>     Filter by scene category
  --family <f>       Filter imported records by model family
  --source <id>      Filter imported records by upstream collection
  --kind <k>         prompt | snippet (imported) or the validation prompt kind
  --language <l>     zh | en
  --tier <t>         official | official-platform | reputable-3rd-party | ...
  --limit <n>        Max results (default 10)
  --min <n>          stats: hide families with fewer records (default 5)
  --json             Machine-readable output
  --notes            Show authoring notes with a prompt
  --verbose          Include info-level lint findings
  --allow-errors     Exit 0 even when lint errors exist

EXAMPLES
  aivp search "rainy portrait" --limit 5
  aivp show scene-10-wuxia-duel --model kling-3.0
  aivp find "starship bridge" --family minimax --kind prompt
  aivp get "lanshu-video-kit::sd-001"
  aivp stats --min 20
  aivp families --unverified
  aivp inspect "lanshu-video-kit::k4-001"
  aivp translate sora-2 veo-3.1 ./my-prompt.txt
  cat prompt.txt | aivp validate kling-3.0
  aivp validate --all --verbose
